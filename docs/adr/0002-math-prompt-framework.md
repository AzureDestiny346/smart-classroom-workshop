# ADR-0002 - 数学专业提示词框架设计决策

**日期**: 2026-08-23  
**状态**: 已批准  
**相关**: ADR-0001  

## 背景

在AI辅助教育领域，通用提示词往往无法满足数学教学的特殊需求。数学学科具有逻辑性强、抽象程度高、表达严谨等特点，需要专门设计的提示词框架来引导AI输出高质量的教学内容。

## 决策

采用**结构化数学专业提示词框架**，包含以下核心要素：

### 1. 角色设定专业化
```
你是一位具有[年限]经验的数学教师，擅长[领域]...
```
- 根据教学场景动态调整角色身份
- 确保AI输出符合教师专业视角

### 2. 任务描述结构化
```
请帮我[具体任务]...
```
- 使用教育学术语定义任务边界
- 明确期望的输出深度和广度

### 3. 输入信息组织化
```
课程：[信息]
学生：[信息]
目标：[信息]
```
- 分类组织教学要素
- 确保AI理解完整教学语境

### 4. 约束条件显式化
```
1. [约束1]
2. [约束2]
```
- 明确数学学科的特殊要求
- 避免AI输出不符合教学规范

### 5. 输出格式规范化
```
格式：[格式]
风格：[风格]
```
- 要求Markdown格式
- 强调数学公式LaTeX渲染
- 内容结构清晰分层

## 理由

1. **专业性**：针对数学学科特点定制，确保内容准确性
2. **可复用性**：模板化设计支持不同知识点的快速适配
3. **可控性**：结构化约束确保AI输出符合教学需求
4. **教育性**：引导教师掌握专业的AI使用方法

## 替代方案比较

### 方案A：通用提示词
- **优点**：简单易用
- **缺点**：无法体现数学学科特点，输出质量不稳定

### 方案B：规则引擎
- **优点**：精确控制
- **缺点**：缺乏灵活性，难以应对复杂教学场景

### 方案C：混合框架（当前选择）
- **优点**：结构化与灵活性平衡，专业性与易用性兼顾
- **缺点**：需要教师理解框架结构

## 影响范围

- 提示词工坊的模板设计
- AI对话系统的提示词生成
- 教师使用指南的编写
