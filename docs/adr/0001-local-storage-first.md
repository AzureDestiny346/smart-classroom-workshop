# 持久化采用 localStorage 优先，经接口抽象保留升级路径

项目定位是演示优先、渐进产品化（2026-08-23 设计决策），完整的服务端持久化（Supabase 全套，2-3 天投入）超出当前需要，因此备课项目、阶段成果与提示词模板全部落浏览器 localStorage，通过 `src/lib/storage.ts` 导出的函数接口与页面隔离，数据键带版本号（`zhike.v1.projects`）预留迁移位。将来产品化时新增一个 Supabase 实现替换即可，页面代码零改动。

## Considered Options

- **Supabase 全套（否）**：依赖当时已在 package.json 中但零引用，直接实现需 2-3 天且引入账号/服务端复杂度，与演示定位不符；相关死依赖已被清理，需要时 `pnpm add` 装回。
- **不持久化，维持 mock（否）**：宣称的核心功能（项目管理/版本）实际不存在，刷新即丢。
