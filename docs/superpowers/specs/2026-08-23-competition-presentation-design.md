# 智课工坊 - 参赛路演演讲设计

**日期**: 2026-08-23  
**演讲时长**: 10 分钟陈述 + 3 分钟评委提问（福建省大学生计算科学与智能创新大赛决赛）  
**演讲对象**: 大赛评委（指定选题一：教育智能体应用）  
**设计目标**: 突出产品完整性和教育创新价值  

## 演讲策略

### 核心信息
"智课工坊通过AI深度融入教学设计流程，让每一位新手教师都能像专家一样备课，实现从'会用AI'到'善用AI'的跨越。"

### 演讲结构设计
```
开场 (1分钟) → 问题痛点 (2分钟) → 解决方案 (4分钟) → 创新亮点 (2分钟) → 价值展望 (1分钟)
```

## 详细演讲内容

### 1. 开场：引人入胜 (1分钟)

**视觉呈现**
- 深蓝色背景，"智课工坊"logo居中
- 快速切换三个场景：教师熬夜备课、课堂中的困惑、学生茫然的眼神

**演讲内容**
> "各位评委好！每天，有数以万计的数学教师为了备好一节课，熬夜查找资料、设计教案、准备习题。平均需要2-4个小时。但即便如此，教学质量依然参差不齐。今天，我想向大家展示一种全新的可能——让AI成为教师的专业助手，而不是简单的工具。"

**核心钩子**
"这不是替代教师，而是赋能教师。不是生成内容，而是培养能力。"

### 2. 问题痛点：引发共鸣 (1.5分钟)

**数据支撑**（定性口径，答辩被问及时说明为团队访谈观察；如后续补做问卷可替换为实测数据）
- 展示备课工作量构成：资料查找、教案撰写、习题设计层层叠加
- 典型痛点清单（叙事化）：
  - 新手教师难以把握重点难点与常见误解
  - 教学设计凭经验，缺少理论框架支撑
  - 重复性劳动挤占课堂创新时间

**故事化表达**
> "张老师是一位有5年经验的初中数学教师。为了准备一节'二次函数'的课，她花了3天时间查阅了8本参考书，设计了3个版本的教案，依然不确定如何突破学生理解的难点。这不是个别现象，而是整个教育行业的普遍困境。"

**情感共鸣点**
"我们在调查中发现，新手教师因为不敢尝试而放弃创新，资深教师因为重复工作而失去热情，这都不是我们希望看到的教育生态。"

### 3. 解决方案：完整展示 (3分钟)

#### 3.1 产品概览 (30秒)
**界面演示**
- 展示产品首页，突出"新建备课项目"的便捷性
- 快速导航四个核心功能模块

**核心定位**
> "智课工坊是一个专为数学教师打造的AI辅助备课平台，基于ADDIE教学设计模型，让备课系统化、专业化、智能化。"

#### 3.2 ADDIE五阶段智能辅助 (1.5分钟)
**分阶段演示**
1. **分析阶段**：自动识别重点难点，预测学生误解
   - 展示知识点图谱生成
   - 展示常见误解提示
   
2. **设计阶段**：基于Bloom认知层次的目标设计
   - 展示递进式目标设置
   - 展示教学策略推荐
   
3. **开发阶段**：生成完整教案和配套习题
   - 展示教案结构化输出
   - 展示习题难度递进设计
   
4. **实施阶段**：课堂节奏把控和互动设计
   - 展示45分钟时间分配
   - 展示师生互动点提示
   
5. **评估阶段**：反思模板和改进建议
   - 展示多维度评价量表
   - 展示持续改进方案

**关键数据**
"整个流程从原来的2-4小时缩短到15-30分钟，质量却有显著提升。"

#### 3.3 提示词工坊创新 (1分钟)
**演示特色**
- 展示7个专业提示词模板
- 展示变量替换功能
- 展示自定义提示词构建

**创新强调**
> "我们最大的创新不是用了AI，而是设计了专门针对数学教育的提示词框架。每个模板都包含角色设定、任务描述、约束条件等结构化要素，确保输出的专业性和教学适用性。"

### 4. 创新亮点：技术突破 (2分钟)

#### 4.1 AI-ADDIE深度融合
**技术原理**
- 展示API架构图
- 展示提示词设计逻辑
- 展示流式交互实现

**创新价值**
"将ADDIE教学设计模型与AI深度融合的完整流程产品，不是简单的内容生成，而是完整的教学设计方法论脚手架。"

#### 4.2 数学专业提示词框架
**框架展示**
- 角色设定：数学教育专家
- 任务描述：结构化教学任务
- 约束条件：数学学科规范
- 输出格式：标准化学术格式

**专业保障**
"所有提示词都经过教育专家验证，确保输出内容符合数学学科特点和教学规范。"

#### 4.3 流式教学交互
**体验展示**
- 实时打字机效果
- 上下文记忆机制
- 追问澄清功能

**用户反馈**
"教师们反馈，这种交互方式让他们感觉像在和一位经验丰富的教学专家对话。"

### 5. 价值展望：未来愿景 (1分钟)

#### 5.1 当前成果
- 可运行的完整 Web 应用（4 页面 + 2 个流式 API），开源可查证
- 完整文档体系：产品规范、领域术语、架构决策记录（ADR）
- 设计目标：单次备课流程从 2-4 小时压缩到 15-30 分钟（现场演示实测口径）

#### 5.2 未来规划
1. **多学科扩展**：物理、化学等理科
2. **智能化升级**：基于课堂实践反馈
3. **生态化建设**：教师资源共享平台

#### 5.3 教育意义
> "我们相信，AI不是教育的威胁，而是教育的机遇。智课工坊不仅是在提供一个工具，更是在构建一个让教师更专业、让学生更受益的教育新生态。"

- 辅色：智慧紫（#8B5CF6）- 创新活力
- 强调色：琥珀橙（#F59E0B）- 温暖关怀

- 正文：Noto Sans SC 24-28px

### 动效设计
- 页面切换：fade + slide-up
- 重点突出：放大 + 高亮
- 数据展示：数字递增动画

## 演讲技巧建议

### 节奏控制
- 前3分钟语速稍快，保持能量
- 中间3分钟放慢，重点展示
- 最后2分钟语速放缓，引发思考

### 互动设计
- 在演示ADDIE流程时，用手势引导注意力
- 展示数据时，看向评委确认理解
- 讲故事时，眼神交流增强感染力

### 应答准备
1. **关于AI取代教师**：强调"辅助"而非"替代"
2. **关于技术门槛**：展示简单易用的界面
3. **关于数据安全**：说明本地存储方案
4. **关于适用范围**：突出数学专业性优势
